# Banking Report Dashboard (Power BI)

# 📊 BankPulse: Interactive Banking Analytics Dashboard (Power BI)

An end-to-end business intelligence project that transforms raw banking transaction records, loan books, and demographic data into a production-grade, interactive executive report. 

### 🚀 Project Repository Includes
* **Power BI File (`.pbix`):** Complete interactive dashboard layout, data model, and visual reports.
* **Data Sources:** Cleaned operational datasets (Excel/CSV mock data).
* **DAX Scripts:** Repository of custom calculations used for operational metrics.

### 🛠️ Key Features
* **ETL & Data Cleaning:** Sanitized and transformed disparate data sources within Power Query—handling null values, structuring schema types, and formatting date dimensions.
* **Robust Data Modeling:** Engineered an optimized **Star Schema** model with direct relationships between fact tables (transactions, accounts) and dimension tables (customers, dates).
* **Advanced DAX Analytics:** Wrote custom DAX expressions to unlock time-intelligence functions (e.g., Year-to-Date trends) and dynamic conditional formatting indicators.
* **Strategic Visualizations:** Structured clean, multi-page layout matrices focusing on **Financial Performance Tracking**, **Loan Portfolio Default Risks**, and **Customer Retention/Churn Outliers**.

### 🧰 Tech Stack & Tools
* **BI Platform:** Power BI Desktop
* **Data Engine:** Power Query (M Formula Language)
* **Analytical Calculations:** DAX (Data Analysis Expressions)
* **Data Storage/Ingestion:** Microsoft Excel / CSV

# EdTech Dashboard (Power BI)

# 📊 EdTechPulse: Student Performance & Engagement Analytics

An end-to-end Business Intelligence project that transforms raw EdTech operational data into an executive-level interactive dashboard. The report provides clear, actionable insights into student behavior, enrollment funnels, course material engagement, and revenue generation.

### 🚀 Project Repository Includes
* **Power BI File (`.pbix`):** Complete interactive dashboard layout, data model, and visual reports.
* **Data Sources:** Sanitized operational datasets (student logs, enrollment records, financial statements).
* **DAX Scripts:** Collection of custom calculations used for advanced time-intelligence metrics.

### 🛠️ Key Features
* **ETL & Data Architecture:** Processed messy, multi-source data through Power Query—resolving structural inconsistencies, removing null values, and building dedicated calendar lookup tables.
* **Star-Schema Modeling:** Developed an optimized relational data model to link high-frequency fact tables (course interactions, payments) with dimensional tables (students, courses, dates).
* **Advanced Behavioral Metrics:** Developed complex DAX formulas to track rolling 7-day course activity, drop-out probabilities, and milestone completion percentages.
* **Executive Visualization:** Implemented interactive multi-page layouts focusing on **Student Success Rates**, **Content Engagement Analysis**, and **Financial Growth / ROI Tracking**.

### 🧰 Tech Stack & Tools
* **BI Platform:** Power BI Desktop
* **Data Transformation Engine:** Power Query (M Language)
* **Analytical Formulas:** DAX (Data Analysis Expressions)
* **Data Source:** Microsoft Excel / CSV
