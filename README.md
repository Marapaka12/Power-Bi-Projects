# Power-Bi-Projects

# Banking Report Dashboard (Power BI)

Created an interactive Power BI dashboard to analyze key banking metrics such as customer accounts, transactions, loan performance, and churn trends. Designed visual reports to provide insights into financial performance and customer behavior for better decision-making.

Tools Used: Power BI, Excel, DAX, Data Cleaning, Data Modeling

# EdTech Dashboard (Power BI)

Designed an interactive Power BI dashboard to analyze student performance, course engagement, and learning trends in an EdTech platform. Visualized key metrics such as enrollments, completion rates, and revenue to support data-driven decision-making and improve learning outcomes.

Tools Used: Power BI, Excel, DAX, Data Modeling, Data Visualization
